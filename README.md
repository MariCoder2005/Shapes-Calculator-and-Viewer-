# Shapes Calculator and Viewer

This project is developed using Java Object-Oriented Programming (OOP) concepts and Swing GUI.

## Features

- Reads shape data from an input file.
- Calculates the area of each shape.
- Saves the calculated areas into an output file.
- Displays each shape using Java Swing.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Swing
- File Handling
